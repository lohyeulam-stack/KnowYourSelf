# Changelog

## 2026-08-22 — Bootstrap v2 archived

固化当前一轮 Knowledge OS 讨论成果：

- Local Detail, Global Summary
- No Recursive Context Boot
- Knowledge Available ≠ Context Loaded
- Conversation is Ephemeral; State is Persistent
- Project Autonomy, Portfolio Governance
- Security Domain First
- L0–L3 Context Hierarchy
- Project Capsule / Feature Capsule
- Project Health Snapshot
- Session Handover
- Project Reliability Loop
- Personal Compounding Loop
- Failure Registry → Rule Promotion → Rule Retirement

本次只做方法论与 Bootstrap 资料固化，不迁移任何私人、公司或项目机密内容。

后续版本继续在同一仓库迭代，不把当前 v2 视为最终标准。
