# Changelog

All notable changes to this project are documented here.

## [Unreleased]

- Continue refining the Knowledge OS architecture through real-world use.
- Add concrete Project Capsule, Feature Capsule, Portfolio Snapshot, and Session Handover examples.
- Expand automated checks only when repeated evidence justifies them.

## [0.2.0] - 2026-08-22

### Added

- `Local Detail, Global Summary` as a top-level architecture principle.
- `No Recursive Context Boot`.
- L0–L3 context hierarchy: Global, Security Domain, Project, Task.
- Project Capsule and Feature Capsule concepts.
- Portfolio Control Plane using thin Project Health Snapshots.
- Session Handover as persistent state for long-running conversations.
- Work Intent Router: PROJECT_WORK / PRODUCT_DISCOVERY / LEARNING / PERSONAL / REVIEW.
- Explicit distinction between Knowledge Available and Context Loaded.
- Public Bootstrap repository structure and GPT → Codex handoff guidance.
- Contribution, security, and community documentation.

### Changed

- Reframed the repository from a personal handoff archive into a vendor-neutral Bootstrap methodology.
- Tightened the default boundary between Human Workspace, Engineering Truth, Agent Context, and file/archive storage.

## [0.1.0] - 2026-08-20

### Added

- Initial Knowledge OS Bootstrap concept.
- Progressive interview model for Discovery before implementation.
- Human / Main Agent / Execution Agent responsibility split.
- Source-of-truth and security-domain principles.
- Pilot-first implementation lifecycle.
