# Knowledge OS Bootstrap Agent Pack v2

这是一套“访谈式搭建包”，不是直接施工包。

## 你现在只需要做一件事

把 `01_主提示词_Knowledge_OS_Bootstrap_Agent_v2.md` 发给新的主 Agent，然后补一句：

> 请完整阅读。现在只进入 Discovery，不允许创建 Notion 页面、数据库、文件夹、自动化，也不允许迁移资料。严格遵守 Local Detail, Global Summary 和 No Recursive Context Boot。每轮只问我一个最高价值问题。

## v2 新增的最高级原则

- Local Detail, Global Summary：项目维护细节，总体只读摘要
- No Recursive Context Boot：根目录只路由，不递归加载
- Knowledge Available ≠ Context Loaded：可搜索不代表加载进上下文
- Conversation is Ephemeral; State is Persistent：聊天是临时计算，状态写入 Handover
- Project Autonomy, Portfolio Governance：项目自治，总体治理
- History is Retrieved, Not Preloaded：历史按需检索，不预加载
- Failure Registry is Queried, Not Fully Injected：只注入相关踩坑
