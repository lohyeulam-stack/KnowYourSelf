# Knowledge OS Highest-Level Principles

1. Local Detail, Global Summary：细节按项目维护，总体只读摘要。
2. No Recursive Context Boot：根目录只负责路由，不递归加载所有项目。
3. Security Domain First：先确定安全域，再确定项目、Feature、Task。
4. Project Autonomy, Portfolio Governance：项目自治，Portfolio 只做健康度、风险、待决策与待验收治理。
5. Knowledge Available ≠ Context Loaded：可搜索不等于进入上下文。
6. Conversation is Ephemeral; State is Persistent：长对话必须压缩成 SESSION_HANDOVER。
7. Context 分层：L0 Global Minimal → L1 Domain → L2 Project → L3 Task。
8. One Fact, One Source of Truth：正式事实禁止多处双向维护。
9. Human Workspace ≠ Agent Workspace：人看工作台，Agent 看合同、Context 和 Task Packet。
10. History is Retrieved, Not Preloaded：历史通过检索进入，不预加载。
11. Failure Registry is Queried, Not Fully Injected：按任务匹配相关 Failure Pattern。
12. Rules Can Retire：Harness 和自动规则允许降级、合并和退休。
