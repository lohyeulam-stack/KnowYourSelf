# Highest-Level Principles

1. **Local Detail, Global Summary** — project details stay local; the global layer reads thin summaries.
2. **No Recursive Context Boot** — root routes; it does not recursively load all projects.
3. **Security Domain First** — route Security Domain → Project → Feature → Task → Topic.
4. **Project Autonomy, Portfolio Governance** — projects own details; portfolio owns health/risk/governance.
5. **Knowledge Available ≠ Context Loaded** — searchable does not mean injected.
6. **Conversation is Ephemeral; State is Persistent** — long sessions become `SESSION_HANDOVER`.
7. **L0 → L1 → L2 → L3** — Global Minimal → Domain → Project → Task.
8. **One Fact, One Source of Truth** — avoid bidirectional duplicate truth.
9. **Human Workspace ≠ Agent Workspace** — human-facing and machine-facing layers are distinct.
10. **History is Retrieved, Not Preloaded** — retrieve only relevant history.
11. **Failure Registry is Queried, Not Fully Injected** — load only relevant failure patterns.
12. **Rules Can Retire** — harness and automation rules may be merged, weakened or retired.
